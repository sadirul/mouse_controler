# Testing

## 1. Automated tests

```bat
python -m pytest
```

All OS-level mouse and window actions are replaced with recording fakes (`tests/conftest.py`);
the suite never moves the real cursor. Hands are generated by `app/simulation.py`, which builds
anatomically plausible 21-point landmarks for any finger configuration, left or right hand, at
any distance.

| Area | Tests |
|---|---|
| Finger detection | `test_gestures.py::test_finger_states`, partial fingers, scale invariance, palm orientation, motion |
| Gesture classification | `test_classification` (13 poses × both hands), fist-is-not-a-pinch, window pose option |
| Pinch detection | hysteresis, single click once, click position, holding never repeats |
| Long press | hold mode, right-click mode, configurable duration |
| Double click | normal, fast (100 ms release), slow pinches = two singles, no split clicks, bounce cooldown |
| Drag state | drag & drop, drag disables scroll/click, hand lost releases, tracking dropouts hold the drag |
| Scroll direction | up/down/left/right, speed, still hand, axis lock, joystick mode, jitter dead zone |
| Gesture priority | emergency over drag, pointing never scrolls, fist freezes cursor |
| Emergency stop | palm hold, short palm ignored, configurable hold, manual stop releases buttons, resume |
| Window gestures | grab/move/release, title-bar mode, four swipes, slow motion ignored, horns, close confirmation, expiry, dialog mode, remapping |
| Cursor | region mapping, clamping, speed, multi-monitor negative coordinates, smoothing, dead zone, precision damping, anchor (drag) motion, relative acceleration |
| Settings persistence | defaults, round trip, partial files, corrupt files, type/range repair, mapping validation, listeners, reset |

Runtime diagnostics (real camera + MediaPipe + gesture engine with a fake mouse):

```bat
python main.py --self-test --quiet        :: from source
HandGestureMouse.exe --self-test          :: packaged build (shows a report dialog)
```

The report is written to `logs/selftest.txt`.

## 2. Manual testing checklist

These need a real person, hand and webcam. Record the date, Windows version, webcam and result.
Start each session with **Start tracking** and confirm the preview shows 21 landmarks on your hand.

### Basic gestures (repeat for each configuration below)

- [ ] Cursor follows the index finger smoothly in all four directions; reaches all four screen edges and corners
- [ ] Hand held still: cursor does not drift or shake
- [ ] Fist: cursor freezes; reopening the index finger resumes from the hand position
- [ ] Thumb + index pinch: exactly **one** left click; holding the pinch for 3 s never repeats the click (long press disabled)
- [ ] Click lands on small targets (e.g. a window's close button, a checkbox)
- [ ] Two quick pinches open a folder on the desktop (double click); two slow pinches select twice without opening
- [ ] Thumb + middle pinch opens a context menu once
- [ ] Long press (0.8 s): in *hold* mode the button stays down until release; in *right click* mode a context menu opens
- [ ] Drag a file from one folder to another; drag a desktop icon; select text by dragging; drag a window by its title bar
- [ ] Hand leaves the camera while dragging: item is dropped within ~0.25 s, no stuck mouse button
- [ ] Two fingers up/down scroll a web page in the matching direction; still fingers do not scroll
- [ ] Two fingers left/right scroll a wide spreadsheet or image horizontally
- [ ] A spread "V" sign does not scroll
- [ ] Three fingers move the active window; it keeps its size; a maximized window is restored first
- [ ] Four-finger swipe up maximizes, down restores/minimizes, left/right snap to half screen
- [ ] Horns hold switches application
- [ ] Thumb + pinky hold shows "Close armed"; doing nothing cancels; repeating closes the window (Notepad with unsaved text asks to save)
- [ ] Desktop / taskbar are never closed or moved (focus the desktop and try)

### Safety

- [ ] Open palm held 1.5 s: emergency stop, red banner, tray icon red, no further actions
- [ ] During a drag, emergency stop releases the mouse button
- [ ] Resume via dashboard button, tray menu and `Ctrl+Alt+R` - each works; gestures cannot resume
- [ ] `Ctrl+Alt+X` stops and `Ctrl+Alt+P` pauses/resumes while the window is hidden in the tray
- [ ] Emergency stop button works while tracking is active
- [ ] Closing the window hides to tray; tray **Exit** releases the camera (webcam LED turns off)
- [ ] With "Keep tracking in the background" off, hiding the window pauses control; showing it resumes

### Packaged executable

- [ ] `build.bat` completes (tests pass, exe built)
- [ ] On a machine without Python: exe starts, settings created in `%APPDATA%\HandGestureMouse`
- [ ] No webcam connected: clear camera error on dashboard, app keeps running
- [ ] `--minimized` starts in the tray; *Start with Windows* launches minimized after sign-in
- [ ] Documentation button opens the bundled user guide

## 3. Verified during development

On the development machine (Windows 11 26200, Python 3.13.5, MediaPipe 0.10.31, built-in
640 × 480 webcam, 1920 × 1080 display at 125 %):

- 128 automated tests pass
- Source and packaged `--self-test`: all checks pass, 25-26 FPS with hand tracking
- GUI smoke test with the real camera: preview, status, live settings changes, camera restart on
  mirror change, clean shutdown with camera release
- Packaged GUI starts in ~3 s, ~150 MB RAM
- Documentation rendered in Chromium (dark, light, 400 px mobile) with animations frozen at
  multiple points to check every gesture animation

Not yet verified (needs the manual checklist above): real-hand gesture accuracy and threshold
tuning, multi-monitor and mixed-DPI setups, Windows 10, other webcams and lighting conditions.
